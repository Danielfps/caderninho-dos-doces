## Sheet: Início
|  | Caderninho — controle de fiado |  |  |
| --- | --- | --- | --- |
|  | Planilha de custos, preços e fiado para qualquer negócio que vende para receber depois: cantina, lanchonete, doces e salgados, lojinha, revenda. |  |  |
|  | Nome do negócio (se quiser) |  |  |
|  | Na primeira vez, preencha nesta ordem: |  |  |
|  | 1 | Meu Mês | Suas contas fixas, quanto você precisa para viver e quantas horas trabalha. A planilha calcula quanto vale a sua hora. |
|  | 2 | Materiais | Se você prepara o que vende: tudo que compra para isso (ingredientes, embalagens), com o tamanho do pacote e o preço. |
|  | 3 | Produtos | O que você vende. Se prepara: quanto a receita rende e quanto tempo leva. Se compra pronto: quanto paga por unidade. |
|  | 4 | Receitas | Só para o que você prepara: o que vai e quanto vai. O preço sugerido aparece em Produtos. |
|  | 5 | Clientes | Quem compra de você, com uma observação se quiser (turma, setor, responsável). |
|  | No dia a dia: |  |  |
|  | • | Vendas | Quem pegou o quê. Sem produto cadastrado? Escreva o que foi e o valor, como no caderno. |
|  | • | Recebi | Quem te pagou, quanto e como (Pix, dinheiro, cartão). |
|  | • | Acertos | Um presente, um desconto ou a correção do valor que alguém deve. |
|  | • | Resumo | Quanto vendeu, quanto já recebeu, quem deve e se o mês pagou suas contas e o seu salário. |
|  | As cores |  |  |
|  |  | Azul clarinho | Você preenche. Pode escrever por cima à vontade. |
|  |  | Branco | A planilha calcula sozinha. Não precisa mexer. |
|  |  | Cinza | Os números mais importantes. |
|  |  | Vermelho | Dívida, ou um preço que dá prejuízo. |
|  |  | Verde | Dinheiro que entrou e conta em dia. |
|  | Como a planilha chega no preço |  |  |
|  | 1 | Custo da unidade | Se prepara: materiais da receita, mais as perdas, divididos pelo rendimento. Se compra pronto: o que paga, mais as perdas. |
|  | 2 | Seu tempo e contas | Só no que você prepara: horas da receita × quanto vale a sua hora, divididas pelo rendimento. É isso que paga as contas fixas e o seu salário. |
|  | 3 | Preço sugerido | Custo completo, mais as taxas e o lucro que você quer. Arredondado para cima. |
|  | 4 | Como está | Compara com o preço que você cobra hoje: Preço bom, Abaixo do sugerido, Não paga o seu tempo ou Prejuízo. |
|  | Dicas |  |  |
|  | • | As linhas que já vêm preenchidas são exemplos. Escreva por cima ou apague. |  |
|  | • | Quilo vira gramas e litro vira ml: 1 kg = 1000 g, 1 litro = 1000 ml. Ovos, potes e peças são em unidades (un). |  |
|  | • | Mudou o preço de algo que você compra? Mude só na aba Materiais (ou em Produtos, se compra pronto): custos e preços sugeridos se atualizam sozinhos. |  |
|  | • | Na aba Vendas, escreva o preço que você cobrou. Assim, se mudar o preço depois, as vendas antigas não mudam. |  |
|  | • | Em breve o app Caderninho vai preencher esta planilha sozinho. |  |
